# Shopping Link Copier｜購物商品連結一鍵複製器

一款專為台灣常用購物網站設計的 Chrome 擴充功能。只要點擊 Chrome 工具列圖示或商品頁上的浮動按鈕，就能一鍵複製商品名稱與整理後的商品網址，方便分享、整理及保存商品資訊。

## 支援網站

目前支援以下 10 個購物網站，均已完成實際 Chrome 商品頁測試：

- PChome 24h 購物
- momo 購物網
- 蝦皮購物
- Yahoo 購物中心
- 博客來
- 誠品線上
- 東森購物
- Coupang 酷澎
- 特力屋
- 露天拍賣

## 主要功能

- **商品資訊一鍵複製**：複製商品標題及商品網址。
- **商品網址清理**：移除廣告及追蹤參數，保留必要的商品識別資訊。
- **商店來源標示**：可在商品標題前加上商店名稱，例如 `[PChome 24h購物]`。
- **複製後增加空白行**：可在網址後增加空白行，方便連續貼上。
- **網頁浮動按鈕**：可開啟、關閉及拖曳調整位置，並記住按鈕位置。
- **Chrome 工具列操作**：點擊擴充功能圖示即可複製目前商品頁資訊。
- **個別網站設定**：可依需求啟用或停用各支援網站。
- **複製成功提示**：可設定提示開關及顯示時間。
- **自動語言切換**：依照 Chrome 介面語言顯示繁體中文或英文。

## 預設設定

- 商店來源標示：開啟
- 複製後增加空白行：開啟
- 網頁浮動按鈕：開啟

以上設定均可在擴充功能設定頁面調整。

## 安裝方式

1. 下載並解壓縮本專案 ZIP 檔。
2. 在 Chrome 網址列輸入 `chrome://extensions`。
3. 開啟右上角的「開發人員模式」。
4. 點擊「載入未封裝項目」。
5. 選擇解壓縮後的 `Shopping-Link-Copier` 資料夾（內含 `manifest.json`）。
6. 開啟支援的購物商品頁，即可使用浮動按鈕或 Chrome 工具列圖示複製。

## 隱私與權限

- 不需要註冊帳號。
- 不需要外部 API 或伺服器。
- 不包含追蹤分析功能。
- 商品資訊及設定均在本機瀏覽器中處理。

## 自動測試

需安裝 Node.js，並在專案根目錄執行：

```bash
node tests/test-url-normalizer.js
node tests/test-momo-title.js
node tests/test-momo-site-detection.js
node tests/test-metadata-titles.js
node tests/test-ruten-site-detection.js
node tests/test-ruten-title.js
```

自動測試用於檢查程式邏輯；購物網站頁面結構可能變動，仍建議在實際商品頁確認複製結果。
